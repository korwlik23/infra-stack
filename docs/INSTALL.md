## ภาพรวม

| ช่วง | ทำอะไร | ใช้เวลา |
|------|--------|---------|
| วันที่ 1 | เช่า VPS, ซื้อโดเมน, ย้ายโดเมนเข้า Cloudflare, ทำ SSH key | 1 ชม. + **รอ Cloudflare หลายชั่วโมง** |
| วันที่ 2 | วาง**คำสั่งเดียว** ตอบคำถาม สร้าง DNS ตามตารางที่สคริปต์บอก | 20–30 นาที |

**ทำไมต้องแยก 2 วัน:** ตอนย้ายโดเมนเข้า Cloudflare ต้องรอให้อินเทอร์เน็ตทั้งโลกรู้จักก่อน
บางครั้งไม่กี่นาที บางครั้งเกือบ 24 ชั่วโมง วันติดตั้งโดเมนต้องเป็น **Active** แล้ว

**วันติดตั้งคุณพิมพ์แค่ 2 คำสั่ง** (`ssh` เข้าเครื่อง + วางคำสั่งติดตั้ง) ที่เหลือเป็นการตอบคำถามบนจอ —
ไม่ต้อง logout/login ระหว่างทาง ไม่ต้องแก้ไฟล์เอง ไม่ต้องรันสคริปต์ซ้ำ

### เตรียมไว้ก่อนเริ่ม

- [ ] คอมพิวเตอร์ Windows 10/11 หรือ Mac ที่ต่ออินเทอร์เน็ต
- [ ] บัตรเครดิต/เดบิต สำหรับจ่ายค่า VPS และโดเมน
- [ ] อีเมลที่ใช้ได้จริง
- [ ] **ที่จดรหัสผ่านที่ปลอดภัย** — แนะนำ password manager (Bitwarden ฟรี, 1Password ฯลฯ)
      คู่มือนี้จะให้จดรหัสหลายตัว อย่าจดใส่ไฟล์ข้อความบนเดสก์ท็อป

### วิธีอ่านคู่มือนี้

- กล่องสีเทาแบบนี้คือ **คำสั่ง** — copy ไปวางใน terminal แล้วกด Enter:

  ```bash
  echo "hello"
  ```

- กล่องที่ขึ้นต้นด้วย `text` คือ **สิ่งที่จะเห็นบนจอ** ไม่ต้องพิมพ์
- อะไรที่อยู่ใน `<...>` ต้อง**เปลี่ยนเป็นค่าของคุณเอง**และลบ `<` `>` ออกด้วย เช่น
  `ssh root@<IP ของ VPS>` → `ssh root@203.0.113.10`
- ในคู่มือนี้สมมติโดเมนของคุณคือ `example.com` — ทุกที่ที่เห็น `example.com` ให้นึกว่าเป็นโดเมนของคุณ

# วันที่ 1 — เตรียมของ

## ขั้นที่ 1: เช่า VPS

VPS คือคอมพิวเตอร์เช่าที่เปิดอยู่ตลอด 24 ชั่วโมงในศูนย์ข้อมูล

1. สมัครกับผู้ให้บริการ เช่น Contabo, Hetzner, GreenCloud, DigitalOcean
2. เลือกสเปก **อย่างน้อย 4 vCPU / 8 GB RAM / 60 GB ดิสก์**
3. ระบบปฏิบัติการ (Image / OS) เลือก **Ubuntu 24.04 LTS** (หรือ 22.04 LTS)
4. ถ้าหน้าสั่งซื้อให้เลือกระหว่าง "Password" กับ "SSH key" → เลือก **Password** ไปก่อน
   แล้วตั้งรหัสผ่าน root ที่เดายาก **จดไว้** (ตอนติดตั้งสคริปต์จะขอ SSH key ของคุณเอง)
5. สั่งซื้อ → รออีเมลว่าเครื่องพร้อม (ไม่กี่นาทีถึงไม่กี่ชั่วโมง)

**✅ สำเร็จเมื่อ:** คุณมี 2 อย่างนี้จดไว้

| ค่า | ตัวอย่าง | หาจากไหน |
|-----|----------|----------|
| **IP ของ VPS** (IPv4) | `203.0.113.10` | อีเมลจากผู้ให้บริการ หรือหน้า control panel |
| **รหัสผ่าน root** | — | ที่ตั้งตอนสั่งซื้อ หรือในอีเมล |

> เครื่องบางเจ้า (AWS, Oracle) ไม่ให้ root แต่ให้ user อย่าง `ubuntu` ที่ใช้ `sudo` ได้ — ใช้แทน root
> ได้ทุกขั้น แค่ใส่ `sudo` ตามที่คู่มือบอก

## ขั้นที่ 2: ซื้อโดเมนและย้ายเข้า Cloudflare

**ทำขั้นนี้เร็วที่สุด** เพราะต้องรอ

### 2.1 ซื้อโดเมน

ซื้อจาก Namecheap, Porkbun, GoDaddy ฯลฯ (หรือซื้อที่ Cloudflare เลยก็ได้ — ถ้าซื้อที่
Cloudflare ข้ามไปขั้น 2.4 ได้ทันที)

### 2.2 เพิ่มโดเมนเข้า Cloudflare

1. สมัครฟรีที่ [dash.cloudflare.com](https://dash.cloudflare.com/sign-up)
2. หน้าแรกกด **Add a domain** (หรือ "Add site") → พิมพ์โดเมน เช่น `example.com` → Continue
3. เลือกแผน **Free** → Continue
4. Cloudflare จะแสดง DNS record ที่มีอยู่ — กด Continue ไปก่อน
5. Cloudflare จะให้ **nameserver 2 ตัว** หน้าตาประมาณ `ada.ns.cloudflare.com` และ
   `bob.ns.cloudflare.com` — **copy เก็บไว้**

### 2.3 เปลี่ยน nameserver ที่ร้านที่ซื้อโดเมน

1. ล็อกอินร้านที่ซื้อโดเมน → เข้าหน้าจัดการโดเมนนั้น → หาเมนู **Nameservers**
2. เปลี่ยนจาก "default" / "Basic DNS" เป็น **Custom DNS** (ชื่อเมนูแต่ละร้านต่างกันเล็กน้อย)
3. ลบ nameserver เดิมทั้งหมด ใส่ 2 ตัวของ Cloudflare แทน → Save
4. กลับไปหน้า Cloudflare → กด **Check nameservers**

**✅ สำเร็จเมื่อ:** ได้อีเมลจาก Cloudflare ว่าโดเมน **Active** และในหน้า Cloudflare
ชื่อโดเมนมีป้ายสีเขียว "Active" — **รอได้ตั้งแต่ไม่กี่นาทีถึง 24 ชั่วโมง** ระหว่างรอทำขั้นที่ 3 ไปก่อนได้

### 2.4 ตั้งค่า SSL ของ Cloudflare (ทำตอนโดเมน Active แล้ว)

Cloudflare → เลือกโดเมน → เมนูซ้าย **SSL/TLS** → **Overview** → เลือกโหมด
**Full (strict)** (ถ้ามีปุ่ม "Configure" ให้กดก่อน แล้วเลือก Custom → Full (strict))

> ⚠️ **ห้ามเลือก Flexible** — เว็บจะวนรีไดเร็กต์ไม่จบ ("too many redirects")

## ขั้นที่ 3: เปิด terminal และสร้าง SSH key

### 3.1 เปิด terminal

terminal คือหน้าต่างสำหรับพิมพ์คำสั่ง เราจะใช้มันสั่งงาน VPS จากระยะไกล

| เครื่อง | วิธีเปิด |
|---------|----------|
| **Windows 10/11** | กดปุ่ม Start → พิมพ์ `PowerShell` → คลิก **Windows PowerShell** |
| **Mac** | กด `Cmd + Space` → พิมพ์ `Terminal` → Enter |

**วาง (paste) ข้อความใน terminal:** Windows = คลิกขวา หรือ `Ctrl + V` · Mac = `Cmd + V`

ลองพิมพ์คำสั่งนี้แล้วกด Enter เพื่อเช็คว่าเครื่องมีโปรแกรม SSH:

```bash
ssh -V
```

**✅ สำเร็จเมื่อ:** เห็นข้อความประมาณ `OpenSSH_9.x ...`
(Windows 10 รุ่นเก่ามากถ้าขึ้นว่าไม่รู้จัก `ssh` → Settings → Apps → Optional features →
Add a feature → **OpenSSH Client** → Install แล้วเปิด PowerShell ใหม่)

### 3.2 สร้าง SSH key (ทำครั้งเดียวต่อคอมพิวเตอร์)

SSH key คือ "กุญแจดิจิทัล" ใช้แทนรหัสผ่าน ปลอดภัยกว่ามาก หลังติดตั้งเสร็จ
**เครื่องจะไม่ยอมให้ login ด้วยรหัสผ่านอีกเลย** — เข้าได้เฉพาะคอมที่มีกุญแจนี้

```bash
ssh-keygen -t ed25519
```

มันจะถาม 3 คำถาม — **กด Enter เฉยๆ ทั้ง 3 ครั้ง** (ใช้ที่เก็บ default และไม่ตั้งรหัสกุญแจ)

> ถ้าขึ้นว่า `... already exists. Overwrite (y/n)?` แปลว่าเคยสร้างไว้แล้ว → พิมพ์ `n`
> แล้ว Enter (**ห้ามตอบ y** ไม่งั้นกุญแจเดิมหาย)

**✅ สำเร็จเมื่อ:** เห็นรูปกรอบสี่เหลี่ยมมีตัวอักษรมั่วๆ (`The key's randomart image is: ...`)

> 🔑 **สำรองกุญแจ:** ไฟล์ `id_ed25519` (ไม่มี `.pub`) ในโฟลเดอร์ `.ssh` ของคุณ
> (Windows: `C:\Users\<ชื่อคุณ>\.ssh\` · Mac: `~/.ssh/`) คือกุญแจดอกเดียวที่เข้าเครื่องได้
> เก็บสำเนาไว้ใน password manager — ถ้าคอมพังและไม่มีสำเนา จะเข้าเครื่องได้ทาง
> console ของผู้ให้บริการเท่านั้น

# วันที่ 2 — ติดตั้ง

ก่อนเริ่ม เช็คว่าโดเมนใน Cloudflare เป็น **Active** แล้ว (ขั้น 2.3) และเปิด Cloudflare ไว้อีกแท็บ —
ระหว่างติดตั้งสคริปต์จะบอกให้สร้าง DNS record

ตลอดวันที่ 2 ใช้ **หน้าต่าง terminal เดียว** ไม่ต้องปิด ไม่ต้องเข้าใหม่

## ขั้นที่ 4: เข้า VPS เป็น root

```bash
ssh root@<IP ของ VPS>
```

สิ่งที่จะเกิด:

1. ครั้งแรกจะถาม `Are you sure you want to continue connecting (yes/no/[fingerprint])?`
   → พิมพ์ **`yes`** (เต็มคำ) แล้ว Enter
2. ถาม `password:` → วางหรือพิมพ์รหัส root แล้ว Enter
   **ตอนพิมพ์รหัสจะไม่มีตัวอักษรหรือจุดขึ้นเลย — เป็นเรื่องปกติ** พิมพ์ต่อให้จบแล้วกด Enter

**✅ สำเร็จเมื่อ:** บรรทัดสุดท้ายเปลี่ยนเป็นประมาณ `root@vmi123456:~#` — ตอนนี้คุณกำลังสั่งงาน VPS อยู่

## ขั้นที่ 5: ช่วง A — เตรียมเครื่องและ user

วางคำสั่งนี้ (เครื่องที่ใช้ user `ubuntu` แทน root: เปลี่ยน `| bash` ท้ายสุดเป็น `| sudo bash`):

```bash
curl -fsSL https://raw.githubusercontent.com/korwlik23/infra-stack/main/prepare.sh | bash
```

สคริปต์เช็คเครื่องก่อน:

```text
==============================================
  InfraStack — ช่วง A: เตรียมเครื่องและ user
==============================================
ตรวจเครื่อง:
  ✅ Ubuntu 24.04.5 LTS   ✅ RAM 7.7 GB   ✅ Disk ว่าง 55 GB
  ✅ IP เครื่องนี้: 203.0.113.10
```

แล้วถามคำถาม 2 ข้อ:

**5.1 รหัสผ่านของ user `deploy`**

```text
  ตั้งรหัสผ่านของ user 'deploy' — ใช้ตอนสั่ง sudo (ไม่ได้ใช้ login)
  จดไว้ในชื่อ "sudo ของ deploy" · พิมพ์แล้วไม่เห็นตัวอักษร เป็นเรื่องปกติ
New password:
```

พิมพ์รหัสใหม่ → Enter → พิมพ์ซ้ำอีกครั้ง → Enter **แล้วจดไว้** (`deploy` คือ user ที่คุณจะใช้แทน root ตั้งแต่นี้)

**5.2 SSH key ของคุณ** (ข้อนี้ขึ้นเฉพาะตอน login ด้วยรหัสผ่าน)

```text
  SSH key สำหรับเข้าเครื่องครั้งหน้า — ยังไม่พบ key ของคุณบนเครื่องนี้
  เปิดหน้าต่างใหม่บนคอมคุณแล้วพิมพ์:
    Windows (PowerShell):  type $env:USERPROFILE\.ssh\id_ed25519.pub
    Mac / Linux:           cat ~/.ssh/id_ed25519.pub
  > 
```

1. **เปิด terminal อีกหน้าต่าง** บนคอมของคุณ (หน้าต่างเดิมเปิดค้างไว้)
2. พิมพ์คำสั่งตามเครื่องของคุณ → จะได้บรรทัดยาวหนึ่งบรรทัดขึ้นต้นด้วย `ssh-ed25519 AAAA...`
3. copy ทั้งบรรทัด → กลับไปหน้าต่าง VPS → วางหลัง `>` → Enter

```text
  ✅ key ถูกต้อง: 256 SHA256:... you@your-pc (ED25519)
```

> กด Enter เปล่าเพื่อข้ามได้ — เครื่องจะยังให้ login ด้วยรหัสผ่าน (ปลอดภัยน้อยกว่า) และสคริปต์
> จะไม่ปิด login แบบรหัสผ่านเพื่อกันคุณล็อกตัวเองออก

จากนั้นรอ 3–8 นาที ไม่ต้องกดอะไร:

```text
[1/5] อัปเดตระบบ + timezone + packages… (2–5 นาที)
[2/5] Docker…
      Docker version 29.x
[3/5] firewall (SSH, HTTP, HTTPS)…
[4/5] Fail2ban…
[5/5] ล็อก SSH (ปิด root login + login ด้วยรหัสผ่าน)…
permitrootlogin no
passwordauthentication no

✅ ช่วง A เสร็จ — 'deploy' มี sudo, SSH key และสิทธิ์ Docker ครบ
🔒 root login ถูกปิดแล้ว (หน้าต่างนี้ไม่หลุด) — ครั้งหน้าเข้าด้วย: ssh deploy@<IP เครื่องนี้>
...
เริ่มติดตั้ง InfraStack ต่อเลยไหม? [Y/n]
```

**กด Enter** — สคริปต์สลับเป็น user `deploy` แล้วเริ่มช่วง B ให้เอง (เหมือนพิมพ์ `su - deploy` เอง)

> ⚠️ **หน้าต่างนี้ไม่หลุด** แม้จะปิด root login แล้ว — การล็อกมีผลกับการเข้าเครื่องครั้งหน้าเท่านั้น
>
> ❌ ถ้าเห็น `❌ ล้มที่: ...` สคริปต์จะโชว์สาเหตุ 20 บรรทัดสุดท้ายให้ — ดู
> [TROUBLESHOOTING.md](TROUBLESHOOTING.md#ช่วง-a--prepare) แก้แล้ววางคำสั่งเดิมซ้ำ (ขั้นที่เสร็จแล้วจะถูกข้าม)

## ขั้นที่ 6: ช่วง B — ติดตั้งระบบ

```text
==============================================
 InfraStack v2.4.0 — ช่วง B: ติดตั้งระบบ   (user: deploy)
==============================================
[1/7] Docker: Docker version 29.x

1) โดเมนของคุณ (เช่น example.com):
```

ตอบคำถามทีละข้อ:

| คำถาม | พิมพ์ |
|-------|-------|
| `1) โดเมนของคุณ` | โดเมนของคุณ เช่น `example.com` (**ไม่ต้องมี** `https://` หรือ `www.`) |

## ขั้นที่ 7: สร้าง DNS record ตามตาราง

ระบบทุกอย่างเปิดแล้ว เหลือแค่ HTTPS ซึ่งต้องรอ DNS — สคริปต์จะโชว์ตารางว่าต้องสร้างอะไร:

```text
══════════════════════════════════════════════
  เหลือขั้นเดียว: สร้าง DNS record ใน Cloudflare
══════════════════════════════════════════════

  Type  Name                   IPv4          สถานะ
  A     traefik.example.com    203.0.113.10  ⏳ ยังไม่มี → Add record
  A     portainer.example.com  203.0.113.10  ⏳ ยังไม่มี → Add record
  A     netdata.example.com    203.0.113.10  ⏳ ยังไม่มี → Add record
  A     grafana.example.com    203.0.113.10  ⏳ ยังไม่มี → Add record
  A     uptime.example.com     203.0.113.10  ⏳ ยังไม่มี → Add record
  A     logs.example.com       203.0.113.10  ⏳ ยังไม่มี → Add record
  A     servers.example.com    203.0.113.10  ⏳ ยังไม่มี → Add record
  A     n8n.example.com        203.0.113.10  ⏳ ยังไม่มี → Add record
  ...
  ทางลัด: record เดียว  A  *.example.com  →  203.0.113.10  ครบทุกชื่อของ BASE_DOMAIN
  เช็คทุก 30 วินาที … (0/8 พร้อม)
```

ไปที่ Cloudflare (บนคอมหรือมือถือก็ได้) → เลือกโดเมน → เมนูซ้าย **DNS** → **Records** → **Add record**
แล้วสร้างทีละแถวตามตาราง:

| ช่อง | ใส่ |
|------|-----|
| Type | `A` |
| Name | ชื่อในคอลัมน์ Name เช่น `portainer.example.com` (Cloudflare ตัดโดเมนหลักให้เหลือ `portainer` เอง) |
| IPv4 address | IP ในคอลัมน์ IPv4 |
| Proxy status | **กดสวิตช์ให้เป็นสีเทา (DNS only)** |
| TTL | Auto |

> **ทางลัด:** สร้าง record เดียว Name = `*` (ดอกจัน) ครบทุกชื่อในตารางทันที
>
> **ทำไมเมฆสีเทา:** ตอนขอใบรับรองครั้งแรก Let's Encrypt ต้องคุยกับเครื่องคุณตรงๆ — เทาผ่านแน่นอน
> อยากเปิดเมฆส้ม (ซ่อน IP + กันโจมตี) ทีหลังได้ อ่าน [11-cloudflare.md](11-cloudflare.md)

**ไม่ต้องกลับมากดอะไร** — ตารางบนจอจะอัปเดตเองทุก 30 วินาที แถวที่สร้างแล้วจะเปลี่ยนเป็น ✅
ถ้าแถวไหนขึ้น `❌ ชี้ไป x.x.x.x (เครื่องอื่น)` แปลว่ามี record เดิมชี้เครื่องอื่นอยู่ → กด **Edit** ที่แถวนั้น
ใน Cloudflare แล้วเปลี่ยน IP

**✅ สำเร็จเมื่อ:**

```text
✅ DNS ครบ 8/8
  ขอ HTTPS cert …… ✅ ครบ 8 ชื่อ
```

> **ต้องไปทำอย่างอื่นก่อน?** (เช่น Cloudflare ยังไม่ Active) กด `Ctrl + C` ได้เลย ระบบจะรอ DNS ต่อเอง
> เบื้องหลังและเปิด HTTPS ให้เมื่อ record ครบ — กลับมาเช็คทีหลังด้วย `infra status`

## ขั้นที่ 8: สร้างบัญชี + จดรหัส

สคริปต์จบด้วยสรุปหน้าเดียว:

```text
══════════════════════════════════════════════
  ✅ ติดตั้งเสร็จ
══════════════════════════════════════════════
⚠️  ทำตอนนี้เลย (ใครเปิดก่อนได้เป็นเจ้าของ):
  1. https://n8n.example.com → สร้างบัญชี owner
  2. https://uptime.example.com → สร้างบัญชี admin
  3. https://servers.example.com → สร้างบัญชี admin

login ได้เลย:
  Portainer  https://portainer.example.com   admin / 3f9c…
  Grafana    https://grafana.example.com   admin / a81e…
  Netdata · Logs · Traefik  (netdata. / logs. / traefik.example.com)   admin / 77d2…

🔑 จดเก็บนอกเครื่อง (password manager) — หายแล้วกู้ข้อมูลไม่ได้:
  BACKUP_ENCRYPTION_PASSWORD   e4a3…
  N8N_ENCRYPTION_KEY           8a22…
  (ดูอีกครั้งได้ด้วย: infra secrets)
```

ทำตามนี้:

1. **เปิด 3 ลิงก์แรกทันที** แล้วสร้างบัญชี — n8n, Uptime Kuma และ Beszel ให้คนแรกที่เปิดหน้าเป็นเจ้าของ
2. **จด** `BACKUP_ENCRYPTION_PASSWORD` และ `N8N_ENCRYPTION_KEY` ลง password manager
   — ถ้าเครื่องพังแล้วไม่มีสองตัวนี้ จะเปิด backup / credentials ใน n8n ไม่ได้เลย
3. จดรหัส login หน้าแอดมิน และรหัส sudo ของ deploy (ขั้น 5.1) ไว้ที่เดียวกัน

> ลืมจด? `infra secrets` แสดงรหัสทั้งหมดอีกครั้ง

**✅ สำเร็จเมื่อ:** ทุกลิงก์เปิดได้ มีรูปกุญแจที่ address bar และ login ผ่าน
