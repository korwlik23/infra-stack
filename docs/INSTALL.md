# วันที่ 1 — เตรียมของ

## ขั้นที่ 1: เช่า VPS

VPS คือคอมพิวเตอร์เช่าที่เปิดอยู่ตลอด 24 ชั่วโมงในศูนย์ข้อมูล

1. สมัครกับผู้ให้บริการ เช่น Contabo, Hetzner, GreenCloud, DigitalOcean
2. เลือกสเปก **อย่างน้อย 4 vCPU / 8 GB RAM / 60 GB ดิสก์** (แนะนำ 6 vCPU / 12 GB / 100 GB)
3. ระบบปฏิบัติการ (Image / OS) เลือก **Ubuntu 24.04 LTS** (หรือ 22.04 LTS)
4. ถ้าหน้าสั่งซื้อให้เลือกระหว่าง "Password" กับ "SSH key" → เลือก **Password** ไปก่อน
   (เราจะทำ SSH key เองในขั้นที่ 4) แล้วตั้งรหัสผ่าน root ที่เดายาก **จดไว้**
5. สั่งซื้อ → รออีเมลว่าเครื่องพร้อม (ไม่กี่นาทีถึงไม่กี่ชั่วโมง)

**✅ สำเร็จเมื่อ:** คุณมี 2 อย่างนี้จดไว้

| ค่า | ตัวอย่าง | หาจากไหน |
|-----|----------|----------|
| **IP ของ VPS** (IPv4) | `203.0.113.10` | อีเมลจากผู้ให้บริการ หรือหน้า control panel |
| **รหัสผ่าน root** | — | ที่ตั้งตอนสั่งซื้อ หรือในอีเมล |

## ขั้นที่ 2: ซื้อโดเมนและย้ายเข้า Cloudflare

**ทำขั้นนี้เร็วที่สุด** เพราะต้องรอ

### 2.1 ซื้อโดเมน

ซื้อจาก Namecheap, Porkbun, GoDaddy ฯลฯ (หรือซื้อที่ Cloudflare เลยก็ได้ — ถ้าซื้อที่
Cloudflare ข้ามไปขั้น 2.3 ได้ทันที)

### 2.2 เพิ่มโดเมนเข้า Cloudflare

1. สมัครฟรีที่ [dash.cloudflare.com](https://dash.cloudflare.com/sign-up)
2. หน้าแรกกด **Add a domain** (หรือ "Add site") → พิมพ์โดเมน เช่น `example.com` → Continue
3. เลือกแผน **Free** → Continue
4. Cloudflare จะแสดง DNS record ที่มีอยู่ — กด Continue ไปก่อน
5. Cloudflare จะให้ **nameserver 2 ตัว** หน้าตาประมาณ `ada.ns.cloudflare.com` และ
   `bob.ns.cloudflare.com` — **copy เก็บไว้**

### 2.3 เปลี่ยน nameserver ที่ร้านที่ซื้อโดเมน

1. ล็อกอินร้านที่ซื้อโดเมน → เข้าหน้าจัดการโดเมนนั้น → หาเมนู **Nameservers**
2. เปลี่ยนจาก "default" / "Basic DNS" เป็น **Custom DNS** (ชื่อเมนูแต่ละร้านต่างกันเล็กน้อย)
3. ลบ nameserver เดิมทั้งหมด ใส่ 2 ตัวของ Cloudflare แทน → Save
4. กลับไปหน้า Cloudflare → กด **Check nameservers**

**✅ สำเร็จเมื่อ:** ได้อีเมลจาก Cloudflare ว่าโดเมน **Active** และในหน้า Cloudflare
ชื่อโดเมนมีป้ายสีเขียว "Active" — **รอได้ตั้งแต่ไม่กี่นาทีถึง 24 ชั่วโมง** ระหว่างรอทำขั้นที่ 3–4 ไปก่อนได้

### 2.4 ตั้งค่า SSL ของ Cloudflare (ทำตอนโดเมน Active แล้ว)

Cloudflare → เลือกโดเมน → เมนูซ้าย **SSL/TLS** → **Overview** → เลือกโหมด
**Full (strict)** (ถ้ามีปุ่ม "Configure" ให้กดก่อน แล้วเลือก Custom → Full (strict))

> ⚠️ **ห้ามเลือก Flexible** — เว็บจะวนรีไดเร็กต์ไม่จบ ("too many redirects")

## ขั้นที่ 3: เปิด terminal บนเครื่องของคุณ

terminal คือหน้าต่างสำหรับพิมพ์คำสั่ง เราจะใช้มันสั่งงาน VPS จากระยะไกล

| เครื่อง | วิธีเปิด |
|---------|----------|
| **Windows 10/11** | กดปุ่ม Start → พิมพ์ `PowerShell` → คลิก **Windows PowerShell** |
| **Mac** | กด `Cmd + Space` → พิมพ์ `Terminal` → Enter |

**วาง (paste) ข้อความใน terminal:** Windows = คลิกขวา หรือ `Ctrl + V` · Mac = `Cmd + V`

ลองพิมพ์คำสั่งนี้แล้วกด Enter เพื่อเช็คว่าเครื่องมีโปรแกรม SSH:

```bash
ssh -V
```

**✅ สำเร็จเมื่อ:** เห็นข้อความประมาณ `OpenSSH_9.x ...`
(Windows 10 รุ่นเก่ามากถ้าขึ้นว่าไม่รู้จัก `ssh` → Settings → Apps → Optional features →
Add a feature → **OpenSSH Client** → Install แล้วเปิด PowerShell ใหม่)

## ขั้นที่ 4: สร้าง SSH key แล้วส่งขึ้นเซิร์ฟเวอร์

SSH key คือ "กุญแจดิจิทัล" ใช้แทนรหัสผ่าน ปลอดภัยกว่ามาก หลังติดตั้งเสร็จ
**เครื่องจะไม่ยอมให้ login ด้วยรหัสผ่านอีกเลย** — เข้าได้เฉพาะคอมที่มีกุญแจนี้

### 4.1 สร้างกุญแจ (ทำครั้งเดียวต่อคอมพิวเตอร์)

พิมพ์ใน terminal บนเครื่องของคุณ (ทั้ง Windows และ Mac ใช้คำสั่งเดียวกัน):

```bash
ssh-keygen -t ed25519
```

มันจะถาม 3 คำถาม — **กด Enter เฉยๆ ทั้ง 3 ครั้ง** (ใช้ที่เก็บ default และไม่ตั้งรหัสกุญแจ)

> ถ้าขึ้นว่า `... already exists. Overwrite (y/n)?` แปลว่าเคยสร้างไว้แล้ว → พิมพ์ `n`
> แล้ว Enter (**ห้ามตอบ y** ไม่งั้นกุญแจเดิมหาย) แล้วข้ามไป 4.2 ได้เลย

**✅ สำเร็จเมื่อ:** เห็นรูปกรอบสี่เหลี่ยมมีตัวอักษรมั่วๆ (`The key's randomart image is: ...`)

### 4.2 login เข้า VPS ด้วยรหัสผ่านครั้งแรก (เพื่อทดสอบ)

```bash
ssh root@<IP ของ VPS>
```

สิ่งที่จะเกิด:

1. ครั้งแรกจะถาม `Are you sure you want to continue connecting (yes/no/[fingerprint])?`
   → พิมพ์ **`yes`** (เต็มคำ) แล้ว Enter
2. ถาม `password:` → วางหรือพิมพ์รหัส root แล้ว Enter
   **ตอนพิมพ์รหัสจะไม่มีตัวอักษรหรือจุดขึ้นเลย — เป็นเรื่องปกติ** พิมพ์ต่อให้จบแล้วกด Enter

**✅ สำเร็จเมื่อ:** บรรทัดสุดท้ายเปลี่ยนเป็นประมาณ `root@vmi123456:~#` — ตอนนี้คุณกำลังสั่งงาน VPS อยู่

พิมพ์ `exit` แล้ว Enter เพื่อออกกลับมาที่เครื่องตัวเอง

### 4.3 ส่งกุญแจขึ้น VPS

เลือกตามเครื่องของคุณ แล้ว copy **ทั้งบรรทัด** (บรรทัดยาว — ต้องได้ครบ):

**Windows (PowerShell):**

```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@<IP ของ VPS> "mkdir -p /root/.ssh && cat >> /root/.ssh/authorized_keys && chmod 700 /root/.ssh && chmod 600 /root/.ssh/authorized_keys"
```

**Mac:**

```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@<IP ของ VPS>
```

มันจะถามรหัส root อีกครั้ง → ใส่แล้ว Enter

### 4.4 ทดสอบว่ากุญแจใช้ได้ (ห้ามข้าม!)

```bash
ssh root@<IP ของ VPS>
```

**✅ สำเร็จเมื่อ:** เข้าเครื่องได้**โดยไม่ถามรหัสผ่าน** ถ้ายังถามรหัสผ่าน = กุญแจยังไม่ถึง →
ดู [TROUBLESHOOTING.md → ssh ยังถามรหัสผ่าน](TROUBLESHOOTING.md#ssh-ยังถามรหัสผ่าน) อย่าเพิ่งไปขั้นต่อไป

> 🔑 **สำรองกุญแจ:** ไฟล์ `id_ed25519` (ไม่มี `.pub`) ในโฟลเดอร์ `.ssh` ของคุณ
> (Windows: `C:\Users\<ชื่อคุณ>\.ssh\` · Mac: `~/.ssh/`) คือกุญแจดอกเดียวที่เข้าเครื่องได้
> เก็บสำเนาไว้ใน password manager — ถ้าคอมพังและไม่มีสำเนา จะเข้าเครื่องได้ทาง
> console ของผู้ให้บริการเท่านั้น

## ขั้นที่ 5: สร้าง DNS record

DNS record คือ "สมุดโทรศัพท์" ที่บอกว่า `portainer.example.com` อยู่ที่ IP ไหน
**ต้องสร้างก่อนติดตั้ง** เพราะทันทีที่ระบบเปิด มันจะขอใบรับรอง HTTPS ทันที

ทำได้เมื่อโดเมนใน Cloudflare เป็น **Active** แล้ว (ขั้น 2.3)

1. Cloudflare → เลือกโดเมน → เมนูซ้าย **DNS** → **Records** → **Add record**
2. กรอกแบบนี้ แล้วกด **Save**:

   | ช่อง | ใส่ |
   |------|-----|
   | Type | `A` |
   | Name | `portainer` |
   | IPv4 address | IP ของ VPS |
   | Proxy status | **กดสวิตช์ให้เป็นสีเทา (DNS only)** |
   | TTL | Auto |

3. ทำซ้ำข้อ 2 ให้ครบทุกชื่อในตารางนี้ (เปลี่ยนแค่ช่อง Name):

   | Name | ใช้กับ |
   |------|--------|
   | `traefik` | หน้า dashboard ของ Traefik |
   | `portainer` | จัดการ Docker |
   | `grafana` | กราฟย้อนหลัง |
   | `netdata` | ดูเครื่องแบบสด |
   | `uptime` | เช็คเว็บล่ม |
   | `logs` | ดู log |
   | `servers` | ดูหลายเครื่อง (Beszel) |

   ครบแล้วจะมี **7 record** ทั้งหมดเป็น Type A ชี้ IP เดียวกัน เมฆสีเทา

> **ทำไมเมฆสีเทา:** ตอนขอใบรับรองครั้งแรก Let's Encrypt ต้องคุยกับเครื่องคุณตรงๆ
> เมฆสีเทาทำให้ผ่านแน่นอน ใช้งานได้ปกติ มี HTTPS ครบ — อยากเปิดเมฆส้ม (ซ่อน IP + กันโจมตี)
> ทีหลังได้ อ่าน [11-cloudflare.md](11-cloudflare.md)

### 5.1 เช็คว่า DNS ใช้ได้แล้ว

บนเครื่องของคุณ (ไม่ใช่ VPS):

```bash
nslookup portainer.<โดเมนของคุณ>
```

**✅ สำเร็จเมื่อ:** ส่วน `Answer` / `Non-authoritative answer` แสดง `Address: <IP ของ VPS>`
ถ้าขึ้น `can't find` / `NXDOMAIN` = ยังไม่พร้อม รอ 5–10 นาทีแล้วลองใหม่

## ขั้นที่ 6: ล็อกเครื่องให้ปลอดภัย (harden)

### 6.1 เข้า VPS แล้วดาวน์โหลด InfraStack

```bash
ssh root@<IP ของ VPS>
```

จากนี้พิมพ์ใน VPS (บรรทัดขึ้นต้นด้วย `root@...`) — copy ทีละกล่อง:

```bash
apt update && apt install -y git
```

```bash
git clone https://github.com/korwlik23/infra-stack.git /opt/infra-stack
cd /opt/infra-stack
```

**✅ สำเร็จเมื่อ:** พิมพ์ `ls` แล้วเห็นไฟล์ `install.sh`, `README.md`, โฟลเดอร์ `docs`, `scripts` ฯลฯ

### 6.2 รันสคริปต์ล็อกเครื่อง

```bash
./scripts/harden.sh
```

ใช้เวลา 2–10 นาที (อัปเดตระบบ) ตัวหนังสือจะวิ่งเยอะ — ปกติ ไม่ต้องกดอะไร

สคริปต์นี้: สร้าง user ชื่อ `deploy` (จากนี้ใช้ตัวนี้แทน root), โอนโฟลเดอร์ `/opt/infra-stack` ให้ deploy,
ปิดการ login ด้วยรหัสผ่าน, ปิดการ login เป็น root, เปิด firewall ให้เหลือแค่ SSH/เว็บ,
ติดตั้งตัวกันคนเดารหัส (Fail2ban)

**ระหว่างทางจะหยุดถาม** `ตั้งรหัสสำหรับ sudo ของ 'deploy'` แล้วตามด้วย `New password:` —
ตั้งรหัสใหม่ 2 ครั้ง (พิมพ์แล้วไม่เห็นตัวอักษร — ปกติ) **จดไว้ในชื่อ "sudo ของ deploy"**
รหัสนี้ใช้ตอนสคริปต์ขอสิทธิ์ผู้ดูแล ไม่ได้ใช้ login

**✅ สำเร็จเมื่อ:** ใกล้ๆ ท้ายมีสองบรรทัดนี้ และจบด้วย `✅ Hardening done.`

```text
permitrootlogin no
passwordauthentication no
```

> ⚠️ ถ้าเห็น `no SSH key found for deploy ... skipping SSH hardening` แปลว่ากุญแจยังไม่ถึง root
> → กลับไปทำขั้น 4.3–4.4 ใหม่ แล้วรัน `./scripts/harden.sh` อีกครั้ง (รันซ้ำได้ ไม่เสียหาย)

### 6.3 ถ้าท้ายสคริปต์เตือนว่า deploy ยังไม่มีรหัส sudo

ปกติขั้น 6.2 ตั้งให้แล้ว ข้ามข้อนี้ได้ — ทำเฉพาะเมื่อเห็นข้อความนี้ท้ายสคริปต์:

```text
⚠️  'deploy' ยังไม่มีรหัส sudo → ยังไม่ปิด root login (root เข้าได้ด้วย key เท่านั้น)
```

**ยังอยู่ในหน้าต่าง root เดิม** รันสองคำสั่งนี้ (ตั้งรหัส แล้วรันสคริปต์ซ้ำเพื่อปิด root login):

```bash
passwd deploy
```

```bash
./scripts/harden.sh
```

**✅ สำเร็จเมื่อ:** `passwd` ตอบว่า `password updated successfully` และรอบนี้ท้ายสคริปต์ขึ้น `permitrootlogin no`

### 6.4 ทดสอบ login เป็น deploy (ห้ามข้าม — กันล็อกตัวเองออก)

**เปิด terminal หน้าต่างใหม่** บนเครื่องของคุณ (หน้าต่าง root เดิมเปิดค้างไว้) แล้ว:

```bash
ssh deploy@<IP ของ VPS>
```

**✅ สำเร็จเมื่อ:** เข้าได้โดยไม่ถามรหัส และเห็น `deploy@...:~$`
ตอนนี้ปิดหน้าต่าง root เดิมได้แล้ว (พิมพ์ `exit`)

> ❌ เข้าไม่ได้? **อย่าปิดหน้าต่าง root** — ดู
> [TROUBLESHOOTING.md → deploy login ไม่ได้](TROUBLESHOOTING.md#ssh-deployip-เข้าไม่ได้)

## ขั้นที่ 7: ติดตั้ง InfraStack

จากนี้ทำทุกอย่างเป็น **deploy** (บรรทัดขึ้นต้นด้วย `deploy@...`)

`install.sh` ออกแบบให้ **รันซ้ำได้เรื่อยๆ** — แต่ละรอบทำต่อจากที่ค้างไว้ และถ้ามันหยุด
จะบอกเสมอว่าต้องทำอะไรก่อนรันอีกรอบ ปกติต้องรัน 3 รอบ:

### 7.1 รอบที่ 1 — ติดตั้ง Docker

```bash
cd /opt/infra-stack
./install.sh
```

- ถ้าถาม `[sudo] password for deploy:` → ใส่**รหัส sudo ของ deploy** (ขั้น 6.3) แล้ว Enter
- ใช้เวลา 1–3 นาที

**✅ สำเร็จเมื่อ:** จบด้วยข้อความ

```text
⚠️  สิทธิ์ group docker มีผลตอน login ใหม่เท่านั้น:
    exit → ssh เข้ามาใหม่ → cd /opt/infra-stack && ./install.sh
```

ทำตามนั้น — ออกแล้วเข้าใหม่:

```bash
exit
```

```bash
ssh deploy@<IP ของ VPS>
```

### 7.2 รอบที่ 2 — สร้างไฟล์ตั้งค่า

```bash
cd /opt/infra-stack
./install.sh
```

**✅ สำเร็จเมื่อ:** จบด้วย

```text
[4/8] Created .env from .env.example
      สุ่มรหัสผ่านให้แล้ว: ...
  แก้แค่ 2 ค่า แล้วรัน ./install.sh อีกครั้ง:
```

ไฟล์ `.env` คือไฟล์ตั้งค่าของเครื่องนี้ (มีรหัสผ่านทุกตัว — **ห้ามส่งให้ใคร ห้ามอัปขึ้น GitHub**)
รหัสผ่านถูกสุ่มให้แล้ว คุณแก้แค่ 2 บรรทัด:

```bash
nano .env
```

`nano` คือโปรแกรมแก้ไฟล์ในหน้าจอ terminal — **ใช้เมาส์คลิกไม่ได้** ใช้ปุ่มลูกศรเลื่อน:

1. เลื่อนไปที่บรรทัด `BASE_DOMAIN=example.com` → ลบ `example.com` (ปุ่ม Backspace)
   → พิมพ์โดเมนของคุณ เช่น `BASE_DOMAIN=mycompany.com` (**ไม่ต้องมี** `https://` หรือ `www.`)
2. บรรทัด `ACME_EMAIL=admin@example.com` → เปลี่ยนเป็นอีเมลจริงของคุณ
   (Let's Encrypt ใช้แจ้งเตือนเรื่องใบรับรอง)
3. บันทึก: กด **`Ctrl + O`** → กด **Enter** (ยืนยันชื่อไฟล์)
4. ออก: กด **`Ctrl + X`**

> บน Mac ก็ใช้ปุ่ม `Ctrl` (ไม่ใช่ `Cmd`)

เช็คว่าแก้ถูก:

```bash
grep -E '^(BASE_DOMAIN|ACME_EMAIL)=' .env
```

**✅ สำเร็จเมื่อ:** เห็นโดเมนและอีเมลของคุณ ไม่มีคำว่า `example.com` แล้ว

### 7.3 รอบที่ 3 — เปิดระบบ

```bash
./install.sh
```

ระหว่างทางมันจะเช็ค DNS ให้:

```text
[6/8] Checking DNS records for core stack…
  ✅ traefik.mycompany.com
  ✅ portainer.mycompany.com
```

**✅ สำเร็จเมื่อ:** จบด้วย

```text
✅ Core stack running.
หน้าแอดมิน (Traefik / Netdata / Dozzle / Redis Insight): user = admin
```

> ❌ ถ้าเห็น `❌ portainer.mycompany.com` และ `ERROR: ยังไม่มี DNS record` →
> สคริปต์หยุดให้เองเพื่อกันโดนแบน สร้าง record ตามที่มันบอก (ขั้นที่ 5) รอ 5 นาที แล้วรัน
> `./install.sh` อีกครั้ง

## ขั้นที่ 8: สร้างบัญชี Portainer (ภายใน 5 นาที!)

Portainer มีกฎความปลอดภัย: ถ้าไม่มีใครสร้างบัญชีแอดมินภายใน 5 นาทีหลังเปิด มันจะล็อกตัวเอง
**ทำขั้นนี้ทันทีหลังขั้น 7.3**

1. เปิดเบราว์เซอร์ (Chrome/Edge/Safari) ไปที่ `https://portainer.<โดเมนของคุณ>`
   - ครั้งแรกอาจรอ 10–60 วินาทีให้ใบรับรองออก — ถ้าขึ้นเตือนความปลอดภัย รอ 1 นาทีแล้วกด Refresh
2. ถ้าหน้าเว็บถาม **Setup token** → กลับไปที่ terminal พิมพ์:

   ```bash
   docker logs portainer 2>&1 | grep -i token
   ```

   copy ตัวอักษรยาวๆ ไปวาง
3. ตั้ง Username (เช่น `admin`) และรหัสผ่าน **อย่างน้อย 16 ตัว** → **Create user** → จดไว้
4. หน้าถัดไปเลือก **Get Started** (ใช้ Docker ในเครื่องนี้)

**✅ สำเร็จเมื่อ:** เห็นหน้า Home มี environment ชื่อ `local` และที่ address bar มี**รูปกุญแจ** (HTTPS ใช้ได้)

> ❌ ขึ้นว่า timed out / ต้อง restart? พิมพ์ `docker restart portainer` แล้วรีบทำข้อ 1–3 ใหม่ภายใน 5 นาที

### เปิดแต่ละหน้าในเบราว์เซอร์

| `https://servers.<โดเมน>` | — | **สร้างบัญชีแอดมินเอง** ทันที |

**✅ สำเร็จเมื่อ:** ทุกหน้าเปิดได้ มีรูปกุญแจ และ login ผ่าน

> ⚠️ Uptime Kuma และ Beszel ใครเปิดก่อนคนนั้นได้เป็นแอดมิน — สร้างบัญชีทันทีหลังเปิด stack
