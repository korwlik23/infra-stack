# p-ai-worker (AI Worker)

Worker ประมวลผลหลังบ้าน — สร้างรูป/คลิป, AI chatbot flow, งานจาก n8n
รับงานจาก queue (Redis หรือ RabbitMQ) → ประมวลผล → อัปโหลดผลลัพธ์ขึ้น R2

## Pattern

```text
n8n / Laravel ──push job──▶ Redis/RabbitMQ ──▶ p-ai-worker ──▶ R2
                                                (FFmpeg, AI API, …)
```

## Deploy

```bash
nano .env          # APP_IMAGE, queue URL, API keys, resource limits
infra deploy p-ai-worker
docker logs -f p-ai-worker
```

## ⚠️ ระวัง

- `mem_limit`/`cpus` ตั้งไว้กัน worker กินทั้งเครื่อง — งาน FFmpeg หนัก ๆ
  บนเครื่อง 8GB ไม่ควรเกิน 2-3GB ต่อ worker
- Scale: `docker compose up -d --scale p-ai-worker=2` (ลบ `container_name` ก่อน)
=== ./docker-compose.yml
services:
  p-ai-worker:
    image: ${APP_IMAGE:?set in .env}
    container_name: p-ai-worker
    restart: unless-stopped
    # log ไม่เกิน 30MB ต่อ container (ค่า default ของ Docker ไม่มีเพดาน — โตจน disk เต็มได้)
    logging:
      driver: json-file
      options:
        max-size: "10m"
        max-file: "3"
    # กันโปรเซสใน container ยกระดับสิทธิ์ (setuid) ถ้าแอปโดนเจาะ — entrypoint ที่ใช้ sudo/su จะใช้ไม่ได้ (docs/31)
    security_opt:
      - no-new-privileges:true
    # build บนเครื่องแทน registry: clone app ไว้ที่ ./src แล้วเปิดบรรทัดล่าง (ดู docs/19-cicd.md)
    # build: ./src
    command: ${WORKER_COMMAND:?set in .env}
    env_file: .env
    networks:
      - backend
    # Worker AI กิน RAM ได้เยอะ — จำกัดไว้กันลากทั้งเครื่อง (ปรับตามงาน)
    mem_limit: ${WORKER_MEM_LIMIT:-2g}
    cpus: ${WORKER_CPUS:-2}

networks:
  backend:
    external: true
    name: backend
