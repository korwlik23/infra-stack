=== ./README.md
# p-n8n (n8n)

Automation platform — ใช้ PostgreSQL เป็น database (ไม่ใช่ SQLite) + HTTPS ผ่าน Traefik

## Deploy

```bash
# database p-n8n_db ถูกสร้างให้แล้วตอน create-project.sh (ถ้า postgres รันอยู่)
# N8N_ENCRYPTION_KEY สุ่มให้แล้ว — จดเก็บนอกเครื่อง: grep N8N_ENCRYPTION_KEY .env
infra deploy p-n8n
```

## ระวัง

- `N8N_ENCRYPTION_KEY` หาย = credentials ใน workflow ทั้งหมดกู้ไม่ได้
- Workflow data อยู่ทั้งใน PostgreSQL และ volume `p-n8n_p-n8n_data` — `infra backup`
  เก็บทั้งคู่ + `.env` (มี `N8N_ENCRYPTION_KEY`) แบบเข้ารหัสให้อัตโนมัติ
- webhook URL ต้องเป็น HTTPS domain จริง (ตั้งผ่าน `WEBHOOK_URL` แล้ว)
=== ./docker-compose.yml
services:
  p-n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: p-n8n
    restart: unless-stopped
    # กันโปรเซสใน container ยกระดับสิทธิ์ (setuid) ถ้าแอปโดนเจาะ — entrypoint ที่ใช้ sudo/su จะใช้ไม่ได้ (docs/31)
    security_opt:
      - no-new-privileges:true
    environment:
      - TZ=${TZ:-Asia/Bangkok}
      - GENERIC_TIMEZONE=${TZ:-Asia/Bangkok}
      - N8N_HOST=${APP_DOMAIN:?set in .env}
      - N8N_PROTOCOL=https
      - WEBHOOK_URL=https://${APP_DOMAIN}/
      - N8N_ENCRYPTION_KEY=${N8N_ENCRYPTION_KEY:?set in .env}
      # PostgreSQL แทน SQLite (production)
      - DB_TYPE=postgresdb
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_PORT=5432
      - DB_POSTGRESDB_DATABASE=${DB_DATABASE:-n8n_db}
      - DB_POSTGRESDB_USER=${DB_USERNAME:?set in .env}
      - DB_POSTGRESDB_PASSWORD=${DB_PASSWORD:?set in .env}
    volumes:
      - p-n8n_data:/home/node/.n8n
    networks:
      - proxy
      - backend
    labels:
      - "traefik.enable=true"
      - "traefik.http.routers.p-n8n.rule=Host(`${APP_DOMAIN}`)"
      - "traefik.http.routers.p-n8n.entrypoints=websecure"
      - "traefik.http.routers.p-n8n.tls.certresolver=letsencrypt"
      - "traefik.http.services.p-n8n.loadbalancer.server.port=5678"

volumes:
  p-n8n_data:

networks:
  proxy:
    external: true
  backend:
    external: true
    name: backend
